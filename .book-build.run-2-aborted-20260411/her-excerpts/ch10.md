# HER Excerpt for Chapter 10

## From §13: Cost Management and Budgeting

**This section addresses the most conspicuous gap in the original harness engineering literature.** Per CIO research, enterprise budgets underestimate AI agent TCO by 40-60%. For multi-hour tasks, uncontrolled cost is the #1 operational risk.

### 13.1 Cost Failure Modes

- **Infinite loops**: An agent in a retry loop can consume thousands of tokens per minute
- **Multi-agent amplification**: Generator + evaluator + sub-agents compound token costs non-linearly
- **Context window bloat**: Approaching context limits triggers expensive compaction operations or session resets
- **Model routing failures**: Expensive model used for tasks that a cheaper model could handle

### 13.2 Cost Control Architecture

```
Per-task cost cap         -- Hard limit; task fails gracefully if exceeded
Per-session cost cap      -- Prevents runaway sessions
Per-hour spend rate alert -- Anomaly detection on spend velocity
Dead-letter queue         -- Tasks exceeding thresholds get queued for human review
Budget allocation         -- Separate budgets for generator/evaluator/sub-agents
```

### 13.3 Cost Optimization Strategies

1. **Semantic routing**: Route simple sub-tasks (summarization, classification) to cheap models (Haiku); reserve expensive models (Opus) for planning and complex reasoning
2. **Observation masking**: 52% cost reduction by hiding irrelevant tool outputs (JetBrains Research, verified)
3. **Sub-agent isolation**: Research in cheap-model sub-agents rather than expensive parent context
4. **Early termination**: Kill sessions that are clearly stuck (loop detection, no-progress-for-N-minutes)
5. **Token metering**: Real-time tracking of input/output tokens per session, per task, per agent

### 13.5 Budget Reality Check

| Metric | Source |
|--------|--------|
| $297 for a $50k contract (best case) | Geoffrey Huntley/Ralph |
| $200 for 6 hours of harness work | Anthropic |
| $3,200-$13,000/month per agent (enterprise) | CIO research |
| 40-60% TCO underestimation | CIO research |

The success stories ($297, $200) represent optimal outcomes with expert human steering. Budget for 3-10x these figures for realistic multi-hour production use.
