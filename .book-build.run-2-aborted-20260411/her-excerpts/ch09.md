## From §5: Pattern 2 Scoped Context Assembly

2. **Scoped Context Assembly**: Multi-level instruction loading (org -> user -> project -> directory)

This pattern loads context at multiple granularities, assembling the most relevant instructions for the current task:

- **Org-level**: Organization-wide policies and conventions (loaded for all projects)
- **User-level**: Individual developer preferences and workflows
- **Project-level**: Project-specific conventions, architecture decisions, and coding standards
- **Directory-level**: Directory-specific instructions for the current working context

The key insight is that not all instructions are equally relevant at all times. A developer working in a Python backend directory doesn't need the React component conventions from the frontend directory. Scoped context assembly loads only the instructions that apply to the current context, reducing noise and token consumption while ensuring the agent has the specific guidance it needs.

This pattern directly addresses the ETH Zurich finding that verbose context files hurt performance -- by scoping instructions to what's immediately relevant, the total volume of injected context stays manageable.

## From §7.1: ETH Zurich AGENTS.md Finding

The ETH Zurich study (arXiv:2602.11988) is one of the few empirical evaluations of persistent instruction files. Key findings:

- **Context files tend to reduce task success rates** compared to providing no repository context at all
- **Inference cost increases by over 20%** when context files are present
- This applies to **both LLM-generated and developer-committed** context files
- The paper recommends describing only **"minimal requirements"** -- verbose instructions and detailed directory trees hurt rather than help

This finding is counterintuitive but critical: the common practice of writing detailed AGENTS.md files with comprehensive documentation, directory trees, and extensive instructions may be actively harming agent performance while simultaneously increasing cost. The optimal approach appears to be minimal, targeted instructions that focus on what the agent needs to know for the specific task at hand.
