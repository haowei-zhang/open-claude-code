**Supply Chain Attacks via MCP Servers/Skills**: Compromised or malicious tools that the agent calls can exfiltrate data, modify behavior, or escalate privileges.
- **Mitigation**: Vet all MCP servers; restrict tool permissions to minimum required; audit tool call logs; run tools in sandboxed environments when possible.

(From Section 12.4 Security Threat Model for Agent Systems)

The full threat model section also covers Indirect Prompt Injection, System Prompt Leakage, Data Exfiltration Through Tool Calls, and Checkpoint-Restore Attacks. The supply chain attack surface is particularly relevant to hooks and lifecycle events because:

- Hooks execute arbitrary shell commands at lifecycle points -- a malicious hook definition is equivalent to a supply chain attack
- Skills loaded on demand are code that the agent trusts and executes -- they should be vetted like npm packages
- MCP servers extend agent capabilities with external tool access and are a supply chain attack surface (treat them like untrusted npm packages)
