# HER Excerpt for Chapter 23

## From §9.1: In-Process Tier

1. **In-Process Subagents**: Same process, isolated context windows (e.g., Claude Code's Agent tool)

In-process subagents offer the tightest integration and lowest latency. The parent agent can directly invoke sub-agents and receive structured results. Context isolation is enforced at the application level. This tier is best for tasks where the sub-agent's work is tightly coupled to the parent's workflow.

Key characteristics:
- Shared process space but isolated context windows
- Direct invocation with structured result return
- Application-level context isolation enforcement
- Lowest latency of the three tiers
- Best for tightly coupled sub-tasks

## From §11.5: Handoff Protocols

- **Full context transfer**: Agent writes a structured handoff document summarizing current state, what's done, what's remaining, and any open questions
- **Incremental review**: Human reviews completed chunks (e.g., every 3 tasks) rather than waiting for the end
- **Checkpoint review**: Mandatory human review at 25% and 75% of task completion to catch goal misinterpretation early

Handoff protocols are critical for multi-session and multi-agent work. When an agent completes its portion of work (whether due to session end, context exhaustion, or task completion), it must leave sufficient context for the next agent (or the same agent in a new session) to continue productively. The structured handoff document is the key artifact -- it captures not just what was done, but what was attempted and failed, what decisions were made and why, and what remains to be done.
