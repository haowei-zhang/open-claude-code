### 7.2 MCP Servers
- Extend capabilities with external tool access
- "Too many tools is bad" -- excess tool descriptions push agents into "the dumb zone" faster
- If an MCP server duplicates CLI functionality well-represented in training data, use the CLI instead
- **Security note**: MCP servers are a supply chain attack surface. Treat them like untrusted npm packages.

**Supply Chain Attacks via MCP Servers/Skills**: Compromised or malicious tools that the agent calls can exfiltrate data, modify behavior, or escalate privileges.
- **Mitigation**: Vet all MCP servers; restrict tool permissions to minimum required; audit tool call logs; run tools in sandboxed environments when possible.

(From Section 12.4 Security Threat Model for Agent Systems)

The full threat model section also covers Indirect Prompt Injection, System Prompt Leakage, Data Exfiltration Through Tool Calls, and Checkpoint-Restore Attacks. The supply chain vector through MCP is particularly dangerous because:

- MCP servers extend capabilities with external tool access -- a compromised server has the agent's full tool privilege scope
- "Too many tools is bad" -- excess tool descriptions push agents into "the dumb zone" faster, compounding the risk because the agent becomes less discerning about which tools to trust
- If an MCP server duplicates CLI functionality well-represented in training data, use the CLI instead (reducing attack surface)

### 6.15 Data Leakage Between Contexts
- **Symptom**: Information leaks between sessions, between sub-agents, or through file-based communication.
- **Evidence**: File-based communication (recommended in Section 9.3) inherently persists data to disk. Without cleanup, sensitive data from one task context can bleed into another.
- **Fix**: Context isolation via separate file namespaces; cleanup protocols; avoid logging sensitive data in progress files; use ephemeral directories for sensitive work.

MCP servers amplify the data leakage risk because they provide external tool access that can transmit context data to third-party services. Every MCP tool call is a potential exfiltration channel. Mitigation requires allowlisting external endpoints and monitoring tool call parameters for sensitive data patterns.
