# HER Excerpts for Chapter 38: Skills: Discovery, Frontmatter, and Progressive Disclosure

## §7.3 — Skills (Progressive Disclosure)

- Agents access specific instructions/tools only when contextually needed
- Treat skills like untrusted npm packages (security risk)
- Reduces cognitive load by not front-loading all instructions

Skills implement the progressive disclosure pattern for the harness's instruction surface. Rather than loading all possible instructions into the system prompt at session start, the harness:

1. **Registers** all available skills during startup
2. **Defers** loading their instructions until the skill is invoked
3. **Injects** the skill's instructions into the context only when needed
4. **Removes** the instructions after the skill completes (or compacts them)

This is analogous to progressive tool expansion (Pattern 9) but for instructions rather than tools. Both patterns solve the same problem: too much context degrades model performance.

## §5 Pattern 9 — Progressive Tool Expansion

**Progressive Tool Expansion**: Start with <20 tools; activate more on demand (not all 60+ at once)

Skills are a form of progressive tool expansion. A skill that wraps a set of tools doesn't expose those tools until the skill is activated. This keeps the base tool count low while providing access to the full catalog when needed.

## §12.4 — Supply Chain via Skills

**Supply Chain Attacks via MCP Servers/Skills**: Compromised or malicious tools that the agent calls can exfiltrate data, modify behavior, or escalate privileges.
- **Mitigation**: Vet all MCP servers; restrict tool permissions to minimum required; audit tool call logs; run tools in sandboxed environments when possible.

Skills are a supply chain attack surface because they execute arbitrary code (via shell commands or sub-agents) with the full permissions of the agent. A malicious skill could:
- Exfiltrate data by reading sensitive files and sending them externally
- Inject malicious instructions into the agent's context
- Escalate privileges by chaining tool calls in unexpected ways

The harness must treat skills like untrusted npm packages: verify their provenance, restrict their permissions, and audit their behavior.
