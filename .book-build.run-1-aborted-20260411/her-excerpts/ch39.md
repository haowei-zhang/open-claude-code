# HER Excerpts for Chapter 39: Slash Commands: 90+ Commands and the Registry

## §7 — Configuration Surfaces

Six configuration surfaces compose a modern harness:

1. **CLAUDE.md / AGENTS.md** (§7.1): Deterministically injected into system prompt every session
2. **MCP Servers** (§7.2): Extend capabilities with external tool access
3. **Skills (Progressive Disclosure)** (§7.3): Agents access specific instructions/tools only when contextually needed
4. **Sub-Agents** (§7.4): Discrete tasks in isolated context windows
5. **Hooks (Lifecycle Events)** (§7.5): User-defined commands at lifecycle events
6. **Back-Pressure Mechanisms** (§7.6): "Swallow the output and only surface errors"

Slash commands are a hybrid configuration surface. They intersect with several of the six surfaces:

- **Prompt-type commands** inject instructions into the context (similar to §7.1 CLAUDE.md but user-initiated)
- **Callback-type commands** execute code directly (similar to §7.5 hooks but user-triggered)
- **Skill-invoking commands** activate progressive disclosure (§7.3)
- **Mode-switching commands** change the permission model (part of §7.6 back-pressure)

The command registry is the lookup table that maps slash commands to their types and implementations. With 90+ built-in commands plus user-defined commands, the registry must support:
- Fast prefix matching for typeahead
- Argument parsing and substitution
- Disambiguation when multiple commands match
- Categorization for help display
- Permission checks before execution
