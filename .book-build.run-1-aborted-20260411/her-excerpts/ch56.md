# HER Excerpts for Chapter 56: What To Build Next: An Opinionated Roadmap

## §11 — Human-in-the-Loop

### Key Patterns for Roadmap

- **Confidence-Based Routing** (§11.1): Above threshold = autonomous; below = queue for approval
- **Tiered Escalation** (§11.2): Tier 1 automated -> Tier 2 agent self-correction -> Tier 3 human front-line -> Tier 4 human expert
- **Async Approval** (§11.3): Agent parks blocked action, continues with non-blocked work. Critical: never fully block on human input
- **Context-Rich Escalation** (§11.4): When escalating, provide what was tried, why it failed, options, and recommendation
- **Handoff Protocols** (§11.5): Full context transfer, incremental review, checkpoint review at 25%/75%

### Roadmap Recommendations
- Implement stronger HITL checkpoints for multi-hour tasks
- Add dead-letter queues for tasks exceeding cost/time thresholds
- Build quality-gate pipelines that combine deterministic + LLM evaluation
- Design explicit human review at 25% and 75% completion milestones

## §13 — Cost Management and Budgeting

### Roadmap Recommendations
- Per-session and per-task cost caps with graceful degradation
- Real-time token metering and anomaly detection
- Cost-per-outcome tracking (not just cost-per-token)
- Budget allocation across generator/evaluator/sub-agents
- Dead-letter queues for cost-exceeded tasks

## §14 — Observability

### Three Pillars
1. **Traces**: Distributed tracing across multi-agent workflows (OpenTelemetry)
2. **Metrics**: Token usage, cost accrual, tool latency, task completion rate, context utilization
3. **Logs**: Structured logging of decisions, tool calls, state transitions

### Roadmap Recommendations
- Multi-hour session dashboard with progress, health, cost, context, quality, alerts
- Loop detection, context rot signal, cost spike, quality degradation, staleness alerting
- Per-step tracing for post-hoc debugging

## §20 — Best Practices

The 12 core principles should guide roadmap prioritization:
1. Context windows are the constraint -> invest in compaction and observation masking
2. Separate generation from evaluation -> build evaluator infrastructure
3. One task per session -> enforce in session protocol
4. Verify before building -> baseline checks at session start
5. Wire in fast feedback loops -> back-pressure stack
6. Repository is single source of truth -> structured artifacts
7. Humans steer, agents execute -> HITL checkpoints
8. Expect eventual consistency -> loop speed optimization
9. Simplify relentlessly -> prune as models improve
10. Control costs actively -> cost caps and monitoring
11. Observe everything -> traces, metrics, logs
12. Secure by default -> least-privilege, idempotency
