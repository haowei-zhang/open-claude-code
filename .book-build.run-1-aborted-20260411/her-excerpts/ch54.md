# HER Excerpts for Chapter 54: The 17 Failure Modes: How CC Defends (or Doesn't)

## §6 — All 17 Failure Modes (Concise)

| # | Failure Mode | Symptom | Fix |
|---|-------------|---------|-----|
| 6.1 | **Context Rot** | Performance degrades 30%+ when key content falls in mid-window positions; agent re-solves, contradicts, loses goals | Active context management (summarization, pruning, progress file); five-stage compaction hierarchy |
| 6.2 | **Premature Completion** | Agent declares work done too early | Comprehensive JSON feature list with all items initially marked "failing"; boolean pass/fail prevents ambiguous states |
| 6.3 | **Self-Evaluation Bias** | Agent rates own work too generously | Separate evaluator agent in fresh context window; ground evaluation in observable artifacts, not self-assessment |
| 6.4 | **Placeholder Implementations** | Agents default to stubs because compiling triggers reward signals | Explicit anti-placeholder instructions ("DO NOT IMPLEMENT PLACEHOLDER"); post-edit hooks detecting stub patterns |
| 6.5 | **Context Anxiety** | Models prematurely wrap up near perceived context limits | Context resets with structured handoffs; don't push to the limit |
| 6.6 | **Silent Failures** | Agent proceeds after tool errors as if successful | Structured output validation after every tool call; semantic verification, not just structural |
| 6.7 | **Infinite Loops** | Retry without progress | Maximum retry counts, exponential backoff, semantic loop detection (same tool + same params N times) |
| 6.8 | **Tool Explosion** | Too many tools degrade selection accuracy | Progressive tool expansion starting with <20; deferred loading via ToolSearch |
| 6.9 | **Compounding Bugs Across Sessions** | New session builds on broken state from previous session | Baseline verification at session start (VERIFY step) before any new work |
| 6.10 | **Yak Shaving / Scope Creep** | Agent wanders into tangential fixes | Strict single-task-per-session constraint; explicit task boundaries |
| 6.11 | **Cost Explosion** | Infinite loops or multi-agent chains rack up hundreds of dollars; TCO underestimated 40-60% | Per-session/per-task cost caps; real-time token metering; dead-letter queues; anomaly detection |
| 6.12 | **Hallucinated Tool Calls** | Agent fabricates tool parameters; structurally valid but semantically wrong | Schema validation on all parameters; semantic validation for critical operations; replay logs |
| 6.13 | **Prompt Injection** | Malicious content manipulates agent behavior; 73% of deployments affected; OpenClaw CVE-2025-53773 | Input sanitization; output filtering; least-privilege; treat all external content as untrusted |
| 6.14 | **Model Regression** | Provider updates break harness behavior silently | Regression test suite; pin model versions; monitor key metrics after updates |
| 6.15 | **Data Leakage** | Information leaks between sessions/sub-agents via file-based communication | Context isolation; cleanup protocols; ephemeral directories; separate file namespaces |
| 6.16 | **Checkpoint-Restore Side Effects** | Agents re-synthesize different requests after restore; duplicate payments, credential reuse (ACRFence) | Record irreversible effects; replay-or-fork semantics; idempotency keys |
| 6.17 | **Goal Misinterpretation** | Agent optimizes for proxy metrics rather than actual intent | Explicit acceptance criteria; human checkpoint at 25% completion; decompose ambiguous goals |
