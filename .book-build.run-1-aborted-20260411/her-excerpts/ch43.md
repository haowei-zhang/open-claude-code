# HER Excerpts for Chapter 43: REPL, PromptInput, Typeahead, Voice, Keybindings

## §11 — Human-in-the-Loop

The REPL is the primary interface for human-in-the-loop interaction. It implements several HITL patterns:

### 11.1 Confidence-Based Routing
- The REPL displays the agent's confidence and reasoning
- A routing layer determines whether to proceed or escalate based on confidence thresholds

### 11.4 Context-Rich Escalation
When the agent escalates to a human through the REPL, it provides:
- What it was trying to do
- What it tried
- Why it failed or is uncertain
- What options it sees
- What it recommends (if it has a preference)

The REPL must render this context clearly so the human can make an informed decision quickly. Typeahead and voice input reduce the friction of human responses, making the HITL loop tighter.

## §7 — Configuration Surfaces

The REPL interacts with multiple configuration surfaces:

1. **CLAUDE.md** (§7.1): The REPL loads and displays the active CLAUDE.md, allowing users to see what instructions are in effect
2. **Hooks** (§7.5): Keybindings can trigger hook execution; the REPL renders hook results
3. **Skills** (§7.3): The typeahead system surfaces available skills; the REPL activates them on invocation
4. **Back-Pressure** (§7.6): The REPL displays only relevant output (errors, warnings) and suppresses verbose success output

Keybindings are themselves a configuration surface -- they determine how the human interacts with the harness. Custom keybindings allow power users to optimize their workflow, while default keybindings provide a consistent experience for new users.
