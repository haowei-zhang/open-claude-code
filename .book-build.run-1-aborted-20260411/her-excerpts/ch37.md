# HER Excerpts for Chapter 37: Hook Execution: Command, Prompt, HTTP, Agent, Function

## §5 Pattern 12 — Deterministic Lifecycle Hooks

**Deterministic Lifecycle Hooks**: Shell commands at 25+ lifecycle points (PreToolUse, PostToolUse, SessionStart, etc.)

Hook execution pipelines vary by hook type, but all share the same deterministic contract:

- **Command hooks**: Execute a shell command synchronously; exit code determines outcome
- **Prompt hooks**: Intercept and modify the prompt; return the modified prompt
- **HTTP hooks**: Send a request to an external service; response determines outcome (with SSRF guard)
- **Agent hooks**: Spawn a sub-agent to evaluate the decision; sub-agent's response determines outcome
- **Function hooks**: Execute in-process TypeScript; return value determines outcome

All hook types share exit-code semantics:
- **0 (success)**: Proceed with the action
- **2 (block)**: Block the action, report the reason to the model
- **Other**: Error occurred, treat as a warning but proceed

## §12.4 — Supply Chain Attacks via MCP/Skills/Hooks

**Supply Chain Attacks via MCP Servers/Skills**: Compromised or malicious tools that the agent calls can exfiltrate data, modify behavior, or escalate privileges.
- **Mitigation**: Vet all MCP servers; restrict tool permissions to minimum required; audit tool call logs; run tools in sandboxed environments when possible.

Hooks are a supply chain attack surface. A malicious hook configured in a project's settings could:
- Exfiltrate data by sending tool call parameters to an external service (via HTTP hooks)
- Modify prompts to inject malicious instructions (via prompt hooks)
- Block legitimate operations while allowing malicious ones (via command hooks)

The harness must defend against these attacks:
- **SSRF guard**: HTTP hooks cannot call internal network addresses
- **Sandboxing**: Command hooks run with restricted permissions
- **Audit logging**: All hook executions are logged for post-hoc review
- **Trust levels**: Hooks from project settings have fewer privileges than hooks from user settings
