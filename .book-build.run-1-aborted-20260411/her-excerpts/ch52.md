# HER Excerpts for Chapter 52: Threat Model: CC Through the Lens of HER Section 12

## §12 — Guardrails, Safety, and Security (Full Section)

### Five-Layer Defense-in-Depth (§12.1)

1. **Prompt-level guardrails**: Instructions in system prompt about what not to do
2. **Schema-level restrictions**: Tool parameter validation, allowlists
3. **Runtime approval system**: Human-in-the-loop for destructive operations
4. **Tool-level validation**: Per-tool safety checks before execution
5. **Lifecycle hooks**: Deterministic shell commands at lifecycle events

### GUARDRAILS.md Protocol (§12.2)

Uses a **Sign** structure:
- **Trigger**: When this guardrail activates
- **Instruction**: What the agent must do
- **Reason**: Why this guardrail exists
- **Provenance**: Who added it and when

### Four Universal Safety Patterns (§12.3)

1. **Artifact Verification**: Check that generated outputs meet structural requirements
2. **Context Rotation**: Periodically reset context to prevent degradation-induced errors
3. **Privilege Boundaries**: Different agents have different permission levels
4. **Rate Limiting**: Prevent runaway loops and excessive API/tool usage

### Security Threat Model (§12.4)

- **Indirect Prompt Injection**: Malicious instructions in files, tool outputs, web pages. Mitigation: input sanitization, treat all external content as untrusted, deterministic validation for security decisions.
- **Supply Chain Attacks via MCP/Skills**: Compromised tools can exfiltrate data or escalate privileges. Mitigation: vet all servers, restrict permissions, audit logs, sandboxed execution.
- **System Prompt Leakage**: Agent tricked into revealing system prompt or configuration. Mitigation: minimize sensitive info in prompts, post-processing filters.
- **Data Exfiltration Through Tool Calls**: Agent sends sensitive data externally. Mitigation: allowlist endpoints, monitor parameters, require human approval for external comms.
- **Checkpoint-Restore Attacks (ACRFence)**: Agents re-synthesize different requests after restore. Two attack classes: Action Replay, Authority Resurrection. Mitigation: record irreversible effects, enforce replay-or-fork semantics, idempotency keys.

### The OpenClaw Incident (§12.5)

CVE-2025-53773 (CVSS 9.6): 135,000 GitHub stars, 21,000 exposed instances. Remote code execution through the agent's tool interface. Agent security is not theoretical.

### Idempotency for External Operations (§12.6)

For multi-hour tasks interacting with external systems, every external operation should be idempotent: generate unique operation ID, check if already performed, store results mapped to IDs, on retry/restore check the ID first.
