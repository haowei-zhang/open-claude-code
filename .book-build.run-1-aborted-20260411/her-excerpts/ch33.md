# HER Excerpts for Chapter 33: Bash Classifier and YOLO Scoring

## §5 Pattern 10 — Command Risk Classification

**Command Risk Classification**: Deterministic pre-parsing and per-tool permission gating

Before any command reaches the model, the harness classifies it by risk level using deterministic rules:

- **Destructive commands** (rm -rf, git push --force, DROP TABLE) require explicit user approval
- **Safe commands** (ls, cat, git status) can proceed automatically
- **Ambiguous commands** fall into a middle tier that may require contextual evaluation

The classification is deterministic -- it does not rely on the model's judgment. This is critical because a model under prompt injection could be coaxed into classifying a dangerous command as safe. The classifier uses pattern matching, allowlists, and denylists to make fast, reliable risk assessments.

The YOLO scoring system extends this classification with a numeric risk score that determines the approval path:
- Low YOLO score: Auto-approved
- Medium YOLO score: Requires user approval unless in auto mode
- High YOLO score: Always requires user approval, even in auto mode

## §12.4 — Security Threat Model

**Indirect Prompt Injection**: Malicious instructions embedded in files, tool outputs, web pages, or database records that the agent processes. The agent follows these injected instructions because it cannot reliably distinguish them from legitimate context.
- **Mitigation**: Input sanitization on all external content; treat file contents and tool outputs as untrusted; use deterministic validation (not LLM judgment) for security-critical decisions.

The classifier is a deterministic defense against prompt injection at the command level. Even if an attacker injects a malicious command into a file that the agent reads, the classifier will flag the command as high-risk and require explicit user approval before execution. This is an instance of Fowler's "computational controls" -- fast, deterministic, and reliable, but limited to patterns the classifier knows about.
